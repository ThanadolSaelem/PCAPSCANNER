Sandbox มี YARA 4.5.0 และได้ทดสอบ real CLI; ไม่ได้แทนการทดสอบ package 4.2.3-4 ใน production image. ผลนี้จึงไม่ยืนยัน production capacity หรือ functional parity 1:1 กับ PCAP-Hunter. DNS candidates, capped beacon/TLS metadata analytics, grounded chat API/UI และ metadata-only STIX route now exist in source/tests, but have not been externally/provider validated. Fast-flux/source-level NXDOMAIN ratio, complete OSINT, Cases basic persistence/notes/analysis links and shared findings/traffic cross-filters are implemented; capped aggregate charts, local IOC search/correlation, immutable export snapshot, PDF/CEF/Navigator exports, MCP and broader detector corpus validation remain parity gaps.
